# GrammarFix Business Model & Unit Economics

## Key Advantage: Zero Marginal Server Inference Cost

Unlike cloud-based AI writing assistants (e.g. Grammarly, QuillBot, LanguageTool Cloud) where every sentence corrected incurs an LLM API call cost ($0.001 - $0.005 per request), **GrammarFix has $0.00 marginal server compute cost.**

---

## Unit Economics Comparison

| Metric | Cloud-Based Writing Assistant | GrammarFix (Local-First) |
|---|---|---|
| **Inference Cost per 10k corrections** | ~$20.00 - $50.00 | **$0.00** |
| **Server Bandwidth per user** | High (All text payload) | **Near zero** (Model downloaded once) |
| **Gross Margin** | 40% - 60% | **92% - 97%** |
| **Offline Availability** | ❌ No | ✅ 100% |
| **Privacy Compliance Overhead** | High (GDPR/HIPAA/Data transfers) | Low (Zero writing stored) |

---

## Revenue Model

1. **Free Tier**: AdMob non-intrusive banner and conservative interstitials between editing sessions. All correction features 100% unlocked.
2. **GrammarFix Pro ($2.99/mo or $19.99/yr)**: 100% ad-free experience.
